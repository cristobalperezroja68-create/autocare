AUTOCARE - quick start
1. Copy this folder ("autocare") into C:\xampp\htdocs\
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Open http://localhost/phpmyadmin -> Import -> choose sql/autocare_db.sql -> Import.
4. Open http://localhost/autocare/
